# 🌐 Interactive Responsive Web App

This is a responsive web application that includes:

- ✅ An interactive quiz with scoring and dynamic question navigation
- 🌦️ A weather app that fetches current weather data using the OpenWeatherMap API
- 📱 Responsive design using CSS Grid and media queries for mobile, tablet, and desktop layouts

---

## 🚀 Features

### 🧠 Quiz App
- Multiple-choice questions
- Real-time feedback on correct/incorrect answers
- Score display at the end
- Simple and clean UI

### 🌍 Weather App
- Input a city name and get real-time weather data
- Uses OpenWeatherMap API
- Displays temperature, city name, and weather description

---

## 📱 Responsive Design

Built with responsive CSS to adapt seamlessly across devices:
- Mobile (≤600px)
- Tablet (601px–900px)
- Desktop (>900px)

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox & Grid)
- Vanilla JavaScript
- OpenWeatherMap API
